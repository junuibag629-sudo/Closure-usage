# 33 클로저 사용하기

### 클로저란
- 클로저는 함수가 생성될 때의 외부 변수를 기억하고, 함수가 종료된 후에도 해당 변수에 접근하거나 사용할 수 있게 하는 기능임. Python에서는 nonlocal을 사용하여 외부 변수의 값을 변경할 수 있으며, 이를 활용하면 변수의 상태를 계속 유지할 수 있음

- 클로저 사용하기전 변수의 사용 범위부터 알아봄
- 예시코드
```
x = 10
def foo():
    print(x)
foo()
print(x)
실행결과
10
10
```
-이처럼 함수를 포함아여 스크립트 전제에서 접근할수있는 변수를 전역 변수라고 부릅니다 특히 전역 번수에 접근할수 있는 범위를 전역 범위라고 함
### 함수 안에서전역 번수 변경하기
- 만약 함수 안에서 전역 변수의 값을 변경하면 어떻게 될까를 알아봄

- 예시코드
```
x = 10
def foo():
    x = 20
    print(x)
foo()
print(x)
실행결과
20
10
```
- 함수 foo x = 20 처럼 값을 변겅함 하지만 출력하면 10이 나옴 이것은 보기에는 같지만 다른 변수임

- 이 같지만 다른 함수를 같게 하려면 global 키워드를 사용해야함
- 예시코드
```
x = 10
def foo():
    global x
    x = 20
    print(x)
foo()
print(x)
실행결과
20
20
```
### 클로저 사용
- 범위를 알았으니 본격적으로 클로저를 사용하려면 형태 만드는 방법은 지역 변수 a, b를 사용 a * x + b를 계산 함수 mul_add를 만든뒤 반환함
- 예시코드
```
def calc():
    a = 3
    b = 5
    def mul_add(x):
        return a * x + b
    return mul_add

c = calc()
print(c(1), c(2), c(3), c(4), c(5))
실행 결과
8 11 14 17 20
```
다른 방법으로 ## 람다(lambda)로 클로저 ## 만들기
- 예시코드
```
def calc():
    a = 3
    d = 5
    return lambda x: a * x + d
c = calc()
print(c(1), c(2), c(3), c(4), c(5))
실행 결과
8 11 14 17 20
```
## 심사문제: 카운트다운 함수 만들기

### 1. 위치 인수 코드 작성 규칙
- 표준 입력으로 정수가 들어감
- 함수를 클로저로 만들어야함
- 정답 작정시 def countdown(n):에 맞춰들여쓰기

### 2. 작성 시 시행착오 
- 클로저를 구현하는 과정에서 중첩 함수의 들여쓰기를 정확하게 적용하지 못하는 실수가 있었음
- nonlocal을 사용하여 외부 함수의 지역 변수를 변경하는 과정에서 변수의 값을 언제 감소시켜야 하는지에 대한 이해가 부족
- 클로저에서는 외부 함수의 변수를 내부 함수가 기억하고 사용할 수 있다는 점을 암
- 변수의 변경 순서와 함수의 실행 순서도 중요하다는 것을 알게 됨

### 3. 실제 구현 내용
- 정수 입력시 입력된 정수가 0까지 줄어듬

### 전체 코드 정리
```
def countdown(n):    
    i = n
    def count():
        nonlocal i
        i -= 1
        return i
    return count

n = int(input())

c = countdown(n)
for i in range(n):
    print(c(), end= ' ')
```
